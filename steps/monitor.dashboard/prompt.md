Собери дашборд мониторинга прода для задачи {{key}} "{{summary}}" ({{url}}, статус {{status}}) в репозитории {{repo}}.

Дашборд описывает три вещи, как задачи мониторинга команды: какие строки лога пишет код задачи, какие панели по ним
строить и на какие алерты смотреть. Цифры потом считаются по логам прода в Elasticsearch; доступа к Prometheus и
Grafana нет, поэтому метрик в дашборде не бывает, только строки лога.

## Формат файла

Запиши дашборд в YAML в файл {{file}}. Схема:

```yaml
id: proj-1234-short-name      # строчные латинские буквы, цифры и дефис; начинается с ключа задачи
title: Короткое название по-русски
description: >-
  Что мониторится и почему, 1-3 предложения.
task: {{key}}
related: [PROJ-1233]          # необязательно: задачи, чьи изменения видны на дашборде
service: <id сервиса>        # сервис по умолчанию из списка выше
headline: [checks, errors]    # необязательно: до трех панелей с числом для карточки обзора
panels:
  - id: checks
    title: Название панели
    hint: 'Какую строку считает панель'   # в кавычках, если внутри есть двоеточие
    type: timeseries          # stat | timeseries | share | top | numbers | lines
    match: ['постоянная часть строки лога']   # все фразы должны быть в строке
    any: ['фраза 1', 'фраза 2']              # хотя бы одна из фраз
    not: ['исключить']                        # ни одной из фраз
    level: [WARN, ERROR]                      # уровни строки
    split:                    # только у timeseries: линия на каждый срез
      - label: noClientData=true
        match: ['noClientData=true']
  - id: failopen
    title: Доля ошибок
    type: share               # доля строк part от строк of
    part: { any: ['ошибка вызова'] }
    of: { any: ['Проверка антифрода', 'ошибка вызова'] }
  - id: channel
    title: Каналы
    type: top                 # самые частые значения
    by: { extract: 'channel = ' }   # слово после префикса в тексте; или level, logger, version, pod
  - id: score
    title: Распределение score
    type: numbers             # распределение числа после префикса
    extract: 'score = '
    interval: 10
  - id: lines
    title: Свежие строки
    type: lines
    any: ['фраза 1', 'фраза 2']
alerts:
  - id: no-checks
    panel: checks             # только по панелям stat, timeseries и share
    when: zero                # ни одной строки за окно
    window: 15m
  - id: errors-high
    panel: failopen
    when: above               # величина выше порога: доля у share, число строк у остальных
    value: 0.05
    window: 15m
  - id: checks-spike
    panel: checks
    when: spike               # величина за окно в factor раз выше средней за baseline
    window: 1h
    baseline: 7d
    factor: 3
```

## Правила

- Фраза - постоянная часть шаблона строки лога из кода, без подстановок: из `log.info("Проверка антифрода RBA для state = {}: status = {}", ...)`
  фразы `Проверка антифрода RBA для state` и `status = success`. Не придумывай строк, которых нет в коде.
- Панелей 4-10: число или график главной строки, доля ошибок или отказов, если они есть, разбивка по значимому полю
  строки и свежие строки. Алерты - только те, что реально помогут: пропажа строк, рост ошибок, всплеск.
- Сервис панели указывай полем `service`, только если он не тот, что у дашборда.
- Никаких телефонов, почты, токенов и имен сотрудников в файле.
- Если задача не пишет своих строк лога, собери дашборд по строкам, которые показывают ее работу, и напиши об этом в
  description.

В ответе верни summary - что мониторит дашборд, 1-3 предложения, и lines - строки лога из кода, по которым он
построен, как они записаны в коде.
