Ты выполняешь шаг "Разбор прогона" по задаче {{key}}: {{summary}}. Нужно понять, что в промптах шагов Task Pilot и в скиллах его агентов стоит поправить, чтобы в следующий раз владельцу не пришлось исправлять то же самое.

Журнал прогона:

{{journal}}

Что можно править: путь для итога, затем где файл лежит сейчас.

{{files}}

Как работать:

1. Для каждого замечания владельца, ответа на вопрос и сбоя из журнала реши, какого общего правила не хватило агенту шага. Разовые решения по этой задаче (выбор стенда, данные для входа, ответ про конкретный PR) правилом не являются: их не переноси. Сбои внешних систем и остановки владельцем тоже не повод править промпт.
2. Реши, где правилу место: правило для любой команды - в промптах шагов и steps/_shared, правило только этой команды (ее сервисы, стенды, соглашения, слова) - в team/rules.md и скиллах команды. Прочитай целиком файлы, которые собираешься править. Правка точечная: одно-два предложения в подходящем месте, в стиле и тоне окружающего текста. Подстановки в двойных фигурных скобках не добавляй и не убирай: их заполняет код шага.
3. Новую версию каждого файла запиши целиком в папку {{staging}} по тому же пути, что в списке: например, steps/qa.stand/prompt.md пишется в {{staging}}/steps/qa.stand/prompt.md. Сами файлы не меняй: правки применит конвейер после подтверждения владельца.
4. Если править нечего, пустой список правок - нормальный итог.

В правках нет имен сотрудников, телефонов, адресов почты, токенов, кодов из SMS и других секретов из ответов владельца. В итоге верни список правок (путь из списка и какое замечание журнала правка закрывает) и итог разбора в 1-3 предложениях.
