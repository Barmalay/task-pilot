## Правила для кода

- Не добивайся зеленой сборки ослаблением тестов: не удаляй и не отключай тесты и не меняй их ожидания без согласия владельца через ask_owner. Изменения существующих тестов владелец все равно увидит на подтверждении коммита.
- Не отступай от утвержденного плана молча: если план не подходит, спроси владельца.
- Правь ровно то, что нужно задаче, в идиоме окружающего кода. Javadoc и комментарии описывают только текущее поведение.
- Сборку и тесты запускай командой из задания: окружение сборки (JDK и прочее) задает конвейер, менять его не нужно.
- Команды выполняются в песочнице без сети: зависимости берутся из локального кэша, скачать новые нельзя. Если без новой зависимости не обойтись, спроси владельца.
